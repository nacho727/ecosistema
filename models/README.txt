Como reemplazar un modelo:

1. Descarga un archivo .glb liviano.
2. Confirma que su licencia permite usarlo en tu trabajo.
3. Renombralo exactamente como el archivo esperado, por ejemplo grillo.glb.
4. Guardalo en esta carpeta.
5. Recarga index_2.html.

Si el modelo tiene animaciones internas, el cargador intentara reproducir automaticamente una animacion llamada idle, walk, fly o run. Si no existe, reproduce la primera animacion disponible.
